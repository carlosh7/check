# CRM (HubSpot / Salesforce / Zoho)

**Sistema → Integraciones → CRM → ➕ Conectar CRM**
1. Plataforma, nombre y API key/token.
2. Click en **🔄 Sincronizar** para importar contactos del CRM a Check (sin duplicados por email).
3. La columna "Última sync" muestra la última importación.

> Los contactos importados quedan disponibles para segmentación y comunicación.
