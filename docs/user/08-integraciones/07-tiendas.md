# Tiendas conectadas (E-commerce)

**Sistema → Integraciones → Tienda → ➕ Conectar tienda**
1. Plataforma (Shopify, WooCommerce, Tiendanube, custom), nombre, URL y API key.
2. **🔄 Sincronizar productos** importa el catálogo de la tienda.
3. Los pedidos/ventas aparecen en **Evento → Negocio → Cupones → Transacciones**.
