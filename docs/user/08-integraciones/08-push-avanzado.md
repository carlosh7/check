# Notificaciones Push avanzadas

**Sistema → Push**
- **Plantillas**: guarda títulos/mensajes reutilizables.
- **Envío segmentado**: elige evento + segmento (todos / asistentes / pendientes) y envía al instante.
- **Programados**: agenda envíos con fecha y hora futura.

> Requiere VAPID configurado (Sistema → Perfil → Activar notificaciones) y asistentes suscritos desde su portal.
