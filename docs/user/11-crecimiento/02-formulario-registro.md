# Formulario de registro público

## Añadir campos personalizados
**Evento → Configuración → Negocio → Formulario → ➕ Nuevo campo**
- Etiqueta, tipo (texto, selección, checkbox, email…), obligatorio sí/no.
- **Lógica condicional**: elige "Solo si: [otro campo]" → el campo aparece solo cuando la respuesta dependiente existe.

## Acompañantes (plus-ones)
En la misma pestaña, define el **cupo de acompañantes** por invitado (0 = desactivado).
El invitado podrá añadirlos en la página de registro; cada acompañante recibe su propio QR de check-in.

## Vista previa
Abre la página de registro del evento (Mis Eventos → link público) para ver los campos tal como los ve el invitado.
