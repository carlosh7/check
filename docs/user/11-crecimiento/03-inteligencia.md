# Inteligencia del evento

**Evento → Configuración → Inteligencia**
- **Asistencia prevista**: proyección basada en histórico y confirmaciones.
- **Recomendaciones IA**: acciones sugeridas (precio, comunicación, ocupación).
- **Etiquetas**: crea etiquetas (ej: VIP, Prensa) para segmentar invitados.

> Los KPIs se recalculan con cada cambio en los invitados.
