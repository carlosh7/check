# Certificados de asistencia

1. **Evento → Configuración → Experiencia → Certificados → ➕ Nueva plantilla**
   - Nombre interno, título y subtítulo que verá el asistente.
2. Genera certificados para todos los asistentes con check-in: botón **⚡** en la fila de la plantilla.
3. **👁** lista los certificados generados con link de descarga PDF por asistente.
4. El asistente también puede verificar/descargar desde su ticket (link público de verificación).
